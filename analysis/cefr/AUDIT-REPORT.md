# 词光（Word Atlas）词表审计报告

> 审计对象：`data/word-atlas.json`，7,298 个词头
> 审计日期：2026-11-23
> 外部基准：EVP / CEFR、NGSL 1.01、COCA 5,000、AWL、NAWL、OpenSubtitles 50k 词频
> 配套数据：`atlas-vs-evp.csv`、`headword-audit.csv`、`evp-bre-senses.csv`、`refs/`

---

## 摘要

这份词表的**工程质量高于同类开源项目，学术信用低于其自我暗示的水平**。

| 维度 | 结论 | 关键数字 |
| --- | --- | --- |
| 分级 | 内部自洽，与 CEFR 系统性错位 | 与 EVP 入门义项一致 54.2%，偏乐观 0.44 级 |
| 义项 | 单词级标签无法承载义项级分级 | 仅 29.0% 的 EVP 义项落在所标等级上 |
| 选词 | 通用核心覆盖良好，学术词有硬缺口 | NGSL 92.4%、COCA 前 2,000 93.1%、AWL 91.9% |
| 边界 | 长尾与专有名词未收敛 | 886 个单词落在 3 万位之后或榜外（12.3%） |
| 规范 | 缺少统一编纂规则 | 拼写双标、5 组屈折重复、72 个过时连字符 |
| 可核验 | 有结构校验，无来源引用 | 音标/例句/搭配 100% 完整，但 0 条出处 |

一句话：**它是一份做得不错的学习产品，不是一份可引用的权威词表。** 两者的差距不在工作量，而在「可追溯」这三个字。

## 0. 审计范围与方法

### 0.1 审计对象

- 文件：`data/word-atlas.json`（7,298 条）、`data/word-atlas.csv`
- 发布形态：`public/atlas/index.json` + `entries/<n>.json`（每块 100 条）
- 上游：`.local/forge/`（文本、图片、音频），**该目录被 `.gitignore` 排除，不在仓库内**

### 0.2 外部基准

| 基准 | 版本/来源 | 规模 | 用途 |
| --- | --- | --- | --- |
| EVP | englishprofile.org，2026-11-23 抓取 | 15,696 行 → 14,586 义项 / 9,751 词头 | CEFR 分级对照 |
| NGSL | Browne, Culligan & Phillips 1.01 | 2,854 条（含补充词） | 通用核心覆盖 |
| COCA 5,000 | 美国当代英语语料库高频表 | 去重 4,350 条，带词性 | 高频覆盖 |
| AWL | Coxhead (2000) | 570 词族 | 学术词覆盖 |
| NAWL | 新学术词表 | 963 条 | 学术词覆盖（扩展） |
| 词频 | OpenSubtitles 2018 英语 50k | 50,000 条 | 频率定位 |

### 0.3 匹配口径

1. 统一小写、去首尾空白、撇号归一（`’→'`）、连字符归一（`‑→-`）。
2. 分级对照优先精确词头；其次「冠词/助动词 + 词」与短语首词（`the moon`、`depend on/upon sb/sth`）；再退词形还原；最后短语内嵌。
3. **等级比较只使用前两类，并剔除专有名词**，得到 4,838 个可比词。
4. 权威词表匹配计入全部词形（NGSL 的 forms 列、AWL 的 subwords、NAWL 的派生形）。

### 0.4 复现

```bash
node analysis/cefr/crawl-evp.cjs "British English"  .tmp-build/raw_bre.json
node analysis/cefr/crawl-evp.cjs "American English" .tmp-build/raw_ame.json
# 后续比对脚本见 .tmp-build/{match2,final2,auth2,auth5}.mjs
```

EVP 站点为 Bubble 单页应用，数据经 Elasticsearch 加密传输，只能通过浏览器把 `Display` 设为 All、
逐屏滚动触发增量渲染后从 DOM 抽取。抽取行数与站点自带计数一致（英式 15,696 / 美式 15,389）。

## 2. 分级审计（vs CEFR / EVP）

### 2.1 可比性：覆盖率断层

| 词光等级 | 词数 | 能在 EVP 找到 | 覆盖率 |
| --- | ---: | ---: | ---: |
| A1 | 785 | 754 | 96.1% |
| A2 | 1,039 | 942 | 90.7% |
| B1 | 1,465 | 1,300 | 88.7% |
| B2 | 2,127 | 1,554 | 73.1% |
| C1 | 1,608 | 419 | **26.1%** |
| C2 | 274 | 4 | **1.5%** |
| 合计 | 7,298 | 4,973 | 68.1% |

A1–B1 段两套体系基本可对话；B2 开始分叉；C1/C2 段已经不是在讨论同一批词。表中 4,973 为全部匹配数，其中 135 个是「词形推断 / 短语内嵌」的宽松匹配，等级比较时剔除，得 4,838 个可比词。

- 词光的 1,882 个 C1/C2 词，只有 **423 个（22.5%）** 在 EVP 中。
- 反向：EVP 的 1,710 个 C2 单词头，词光收了 1,113 个（65%），但绝大多数被标成 B2/C1。
- 两套「高级词」几乎是两个不同的集合：词光收 `avenge / bestow / deplore / vortex / preclude / staphylococcus`，EVP 收 `threshold / inherent / empirical / whereby / curb`。

### 2.2 一致率：取决于归并规则

CEFR 没有「词的等级」，只有「义项的等级」。要跟单词级标签比较，必须先选归并规则（下表的 min 即「入门义项」——该词等级最低的那条义项，不是词典里的第一个释义）：

| 归并规则 | 完全一致 | ±1 级内 | 平均偏差 |
| --- | ---: | ---: | ---: |
| `min` 取最易义项 | **54.2%** | **93.2%** | −0.44 |
| `mode` 取义项最多的等级 | 47.7% | 86.2% | −0.65 |
| `max` 取最难义项 | 31.6% | 66.3% | −1.29 |

分母为 4,838 个可比词。**同一批数据，只换归并规则，一致率从 93% 掉到 66%。**
这说明「词级标签准不准」不是数据质量问题，而是定义问题。

### 2.3 混淆矩阵与系统性偏移

行 = 词光标注，列 = EVP 该词最易义项等级：

| 词光 \ EVP | A1 | A2 | B1 | B2 | C1 | C2 | 合计 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| A1 | **490** | 237 | 16 | 0 | 0 | 0 | 743 |
| A2 | 21 | **491** | 391 | 25 | 1 | 3 | 932 |
| B1 | 5 | 73 | **787** | 367 | 29 | 15 | 1,276 |
| B2 | 1 | 8 | 89 | **748** | 430 | 225 | 1,501 |
| C1 | 0 | 0 | 0 | 10 | 103 | **271** | 384 |
| C2 | 0 | 0 | 0 | 0 | 0 | 2 | 2 |

读法：

- **对角线下方的质量很小**（词光标得比 EVP 难的只有 14 例，占比 0.3%）；
- **对角线上方有一条稳定的偏移带**：词光 A1 有 34% 落到 A2 及以上，A2 有 45% 落到 B1 及以上，B2 有 44% 落到 C1/C2，**C1 有 71% 落到 C2**。
- 结论：**词光系统性偏乐观约半级，越往高级偏得越多。**

### 2.4 义项维度：一个标签最多覆盖三成

4,838 个可比词对应 **11,439 个 EVP 义项**，其中只有 **3,319 个（29.0%）** 的等级等于词光标注。

| 指标 | 数值 |
| --- | ---: |
| 全部义项都在所标等级上的词 | 1,485（30.7%） |
| 没有任何一个义项在所标等级上的词 | 2,144（44.3%） |
| 跨 ≥2 个等级的义项的词 | 1,757（36.3%） |
| 跨 2 / 3 / 4 / 5 / 6 级 | 1,072 / 386 / 175 / 78 / 46 |

最能说明问题的是词光**自己的义项数**与 EVP 跨级率的关系：

| 词光给出的义项数 | 词数 | EVP 跨 ≥2 级 | 占比 |
| --- | ---: | ---: | ---: |
| 1 | 1,454 | 71 | 4.9% |
| 2 | 1,873 | 676 | 36.1% |
| 3+ | 1,511 | 1,010 | **66.8%** |

词光已经识别出这些词是多义词（写了 3 个中文义项），却仍只给一个等级。**三分之二的多义词，其不同义项在 CEFR 里分属不同等级。**

### 2.5 典型案例

**A. 把「概念简单」当成「学得早」**

| 词 | 词光 | EVP | 备注 |
| --- | --- | --- | --- |
| rainy / toothpaste / tiger / giraffe / strawberry | A1 | B1 | 具体名词，教材出现晚 |
| gym / lady / writer / pants / alphabet | A1 | B1 | 同上 |
| tool / lower / gardening / mother-in-law | A2 | B2 | 差 2 级 |

**B. 标到了另一个义项**

| 词 | 词光 | EVP 各义项 | 错位原因 |
| --- | --- | --- | --- |
| chip | B2 | A1 薯条 / B2 芯片 / C2 介入 | 词光取「芯片」 |
| bear | B2 | A2 熊 / B2 忍受 / C1 携带 / C2 生育 | 词光取「忍受」 |
| slim | B1 | A1 苗条 / C2 渺茫 | 词光取「微弱」 |
| soul | B2 | A2 灵魂乐 / B2 灵魂 / B2 人 | 词光取哲学义 |
| comparative | B2 | A2 比较级（语法）/ C1 相对的 | 词光取「相对的」 |

**C. 高级段越界**

`avenge`、`bestow`、`deplore`、`splint`、`infantry`、`depute`、`wreathe`、`vortex`、`preclude`、`surmise`、`staphylococcus`、`pilferage`——偏文学、偏生僻、甚至专业术语。CEFR 的 C2 不是「最难的词」，而是「熟练使用者仍会用到的高阶词」。

## 3. 选词审计（vs NGSL / COCA / AWL / NAWL）

### 3.1 覆盖

| 基准 | 规模 | 词光覆盖 | 缺口 |
| --- | ---: | ---: | ---: |
| NGSL 内容词 | 2,815 | **92.4%** | 214 |
| COCA 前 2,000 内容词 | 1,863 | **93.1%** | 128 |
| COCA 前 1,000 名词 | 410 | 97.1% | 12 |
| COCA 前 1,000 动词 | 218 | 94.0% | 13（含 8 个助动词） |
| COCA 前 1,000 形容词 | 110 | 92.7% | 8 |
| AWL 词族 | 570 | **91.9%** | 46 |
| NAWL | 963 | 59.8% | 387 |
| EVP 单词头 | 6,547 | 72.9% | 1,777 |

通用英语的骨架是完整的。NAWL 偏低属正常——它偏向理工医科（`abdominal`、`amino`、`algorithm`），不是雅思主战场。

### 3.2 缺口 A：高频实义词

COCA 前 1,000 中缺失的实义词：

- 动词：`go`(35)、`work`(117)、`thank`(498)、`check`(857)、`reveal`(930)
- 形容词：`federal`(494)、`likely`(625)、`past`(681)、`happy`(748)、`entire`(871)、`religious`(887)、`deep`(978)
- 名词：`part`(178)、`work`(199)、`center`(531)、`page`(709)、`song`(854)、`trial`(901)

其中 `work` 同时是高频动词与名词，`go` 是基础移动动词，`happy`、`deep` 是 A2 级别的核心形容词。这些不是「生僻词漏收」，是「基础词漏收」。

### 3.3 缺口 B：学术词（对雅思产品影响最大）

AWL 570 族中缺 46 族：

| 子表 | 缺失词族 |
| --- | --- |
| S1 | legislate |
| S2 | aspect, equate, perceive, potential |
| S3 | emphasis, scheme |
| S4 | contrast, ethnic, internal, output, parallel, subsequent |
| S5 | enable, notion, revenue, whereas |
| S6 | acknowledge, federal, incorporate, index, rational |
| S7 | foundation, paradigm, phenomenon |
| S8 | commodity, complement, infrastructure, minimise, widespread |
| S9 | anticipate, duration, ethic, passive, preliminary, protocol, qualitative, rigid, scenario, supplement, trigger |
| S10 | albeit, invoke, levy, nonetheless, pose |

`aspect`、`potential`、`emphasis`、`contrast`、`phenomenon`、`whereas`、`foundation`、`infrastructure`、`scenario`、`trigger` 是雅思大作文的骨架词。这份清单是本报告中最可执行的一条改进依据。

### 3.4 边界：长尾与专有名词

以 OpenSubtitles 50k 词频表定位（仅能评估单词，多词/连字符条目另计）：

| 等级 | 单词数 | 词频 > 3 万或不在榜 | 占比 |
| --- | ---: | ---: | ---: |
| A1 | 783 | 2 | 0.3% |
| A2 | 1,016 | 23 | 2.3% |
| B1 | 1,432 | 33 | 2.3% |
| B2 | 2,113 | 114 | 5.4% |
| C1 | 1,594 | 510 | 32.0% |
| C2 | 272 | 204 | 75.0% |
| 合计 | 7,210 | **886** | **12.3%** |

另有 88 个多词/连字符条目（`post office`、`day off`、`in advance`）不计入上述分母；其中 52 个因整串不在词频榜而计入长尾标记，其余 36 个连字符条目本身在榜（如 `t-shirt`）。

C1 段 32%、C2 段 75% 落在长尾是合理的——高级词本来就低频。真正扎眼的是 A2/B1 段那 56 个：`photocopier`、`rucksack`、`dustbin`、`ladybird`、`suncream`、`ladybird`，词频都在 2 万位之后，标成 A2/B1 更像「教材里出现过」而不是「学习者该先会」。

**专有名词 98 个**未单独归类：7 个星期、10 个月份、25 个地名、16 个国籍/语言，另有 `God`、`Bible`、`Islam`、`Marxism`、`Leninism`、`Saturn`、`PC`、`ZIP code`。它们与普通词混在同一分级体系里，既拉低「A1 词汇量」的含金量，也让 CEFR 对照失真（EVP 基本不收专有名词）。

### 3.5 分级与词频的单调性

| 等级 | 中位词频排名 | P25 | P75 |
| --- | ---: | ---: | ---: |
| A1 | 866 | 348 | 1,981 |
| A2 | 2,607 | 1,252 | 5,751 |
| B1 | 4,467 | 2,553 | 7,940 |
| B2 | 8,636 | 5,172 | 14,604 |
| C1 | 18,399 | 12,047 | 28,581 |
| C2 | 30,603 | 20,406 | 38,431 |

等级与词频的秩相关 **ρ = 0.71**，中位排名严格单调。**分级确实跟着使用频率走**，这是这份估计值最可信的部分。

## 4. 规范性审计（内部一致性）

### 4.1 拼写策略：同一件事三种做法

| 类型 | 数量 | 例子 |
| --- | ---: | --- |
| 同一词的美/英拼写**都收** | 12 组 | favourite + favorite、organise + organize、grey + gray、programme + program、licence + license、practise + practice、analyse + analyze、realise + realize、behaviour + behavior、catalogue + catalog、jewellery + jewelry、aeroplane + airplane |
| 只收英式拼写 | 8 组 | colour、centre、theatre、metre、defence、offence、neighbour、travelling |
| 只收美式拼写 | 0 组 | — |
| 同一词头合并两种拼写 | 1 条 | `cheque/check`（全库唯一带斜杠的词头） |

另有 15 组**不同词**的英/美用词差异（film + movie、flat + apartment、lorry + truck、petrol + gas、rubber + eraser、football + soccer、holiday + vacation、shop + store、underground + subway、queue + line、chemist + drugstore、biscuit + cookie、timetable + schedule、rubbish + garbage、autumn + fall），这些属于「收词范围」而非「拼写规范」，可以保留，但应意识到它们占了 30 个词位。

### 4.2 词形策略：原形与屈折形并存

| 组 | 说明 |
| --- | --- |
| chip + chips | 两条独立词条 |
| child + children | 同上 |
| foot + feet | 同上 |
| woman + women | 同上 |
| person + people | 同上 |

正规词表以词元（lemma）为词头，屈折形不单列。这 5 组属于词元化不彻底。

### 4.3 词头形式

| 问题 | 数量 | 例子 |
| --- | ---: | --- |
| 过时连字符写法 | 72 | `dining-room`、`tape-recorder`、`mid-day`、`bread-earner`、`epoch-making`、`short-weight`、`above-mentioned`、`bottom-line` |
| 全大写（应为小写） | 2 | `TRUE`、`FALSE` |
| 词头形式不规范 | 1 | `Mister`（词典词头应为 Mr / mister） |
| 月份不成套 | 缺 2 | 有 10 个月份，缺 March（并入 `march` 动词）、May（`may` 整个词都没有） |
| 带标点 | 3 | `p.m.`、`a.m.`、`cheque/check` |

72 个连字符中，`dining-room`、`tape-recorder`、`tape-recording`、`mid-day`、`note-taking`、`bread-earner`、`epoch-making`、`short-weight` 等属于 1980 年代教材写法，现代词典作 `dining room`、`tape recorder`、`midday`。这是词头来源可能继承自旧版双语词表的间接证据。

### 4.4 数据错误与不一致

| 条目 | 问题 | 建议 |
| --- | --- | --- |
| `TRUE` / `FALSE` | 全大写，疑似 Excel/CSV 转换残留 | 改为 `true` / `false`（id 已是 `true`/`false`，无迁移成本） |
| `Mister` | 词头应为 `Mr` 或 `mister` | 改 `mister`，释义保留「先生」 |
| `cheque/check` | 一个词头承载两种拼写与两个义项体系 | 拆为 `cheque`（英）与 `check`（美/通用） |
| March / May | 月份缺失 | 补 `March`（三月）、`May`（五月）；`may` 情态动词也缺失，建议合并为多义项 |
| `TRUE` 的 `id` | 已是 `true`，但 `w` 未同步 | 只改 `w` 即可，媒体文件名不受影响 |

## 5. 标注质量审计

### 5.1 结构层：优秀

- 7,298 条全部通过 `id` 规范（`^[a-z0-9-]{1,64}$`）、唯一性、等级/话题索引范围校验。
- `syn_sense` 与 `syn` 等长且下标合法，关系表可追溯到义项。
- 媒体位标记与实际文件一一对应，0 缺失。

### 5.2 内容层：不可核验

| 项目 | 现状 | 风险 |
| --- | --- | --- |
| 释义来源 | 大模型按统一规范撰写 | 无出处，无法逐条回溯 |
| 人工审校 | 项目自述「尚未逐条人工审校」 | 错误率未知 |
| `cefr` 字段 | 文档定义为「估计难度」 | 易被读者当作官方分级 |
| 义项上限 | 每词 ≤3 | `in` 在 EVP 有 15 个义项，`on` 有 19 个 |

| 45 条义项中文重复 | 同一词不同词性的中文释义完全相同（`after` 的 prep./conj. 都是「在……之后」） | 不算错，但中文侧丢失了词性区分 |

### 5.3 内容抽检

未做全量人工复核，但可给出结构性判断：字段齐全、格式统一、例句均含词头（自动校验有 `headwordNotInExample` 警告项）。
真正的内容准确性（释义是否贴切、例句是否自然、搭配是否地道）超出本次自动化审计能力，需人工抽样。

## 6. 结论与评分

| 维度 | 评分（5 分制） | 依据 |
| --- | ---: | --- |
| 选词可追溯性 | **0.5** | 无 `source` 字段、无参照词表、无版本对应；CEFR 字段为「估计」 |
| 通用核心覆盖 | **4.5** | NGSL 92.4%、COCA 前 2,000 93.1%、前 1,000 名词 97.1% |
| 学术词覆盖 | **3.5** | AWL 91.9%，但缺 46 族核心学术词 |
| 分级可信度 | **3.5** | ρ=0.71 内部自洽；与 EVP 仅 54.2% 一致 |
| 边界控制 | **2.5** | 886 词长尾、98 个专有名词、84 个 A1–B1 低频词 |
| 内部一致性 | **2.5** | 拼写双标、5 组屈折重复、72 个过时连字符、4 处词头错误 |
| 标注完整度 | **4.0** | 音标/例句/搭配 100%，但无引用、义项上限 3 |
| **综合** | **3.0** | 工程过关，学术信用不足 |

### 三条核心判断

1. **分级是一把自洽但偏松的尺子。** 它跟着词频走（ρ=0.71），但整体比 CEFR 乐观 0.44 级，C1 段偏差最大（71% 被判 C2）。
2. **「按词分级」与「按义项分级」的差价是结构性的，不是标注错误。** 44.3% 的词在 EVP 中没有任何义项落在所标等级上；词光自己的 3 义项词有 66.8% 在 EVP 跨级。
3. **权威性缺的是三根支柱：可追溯的来源、可核验的引用、可复现的选词规则。** 这三项都可以补，且补法不同——第一项改文档，第二项加字段，第三项重建流程。

## 附录 C：口径与局限

1. **未做义项级语义对齐。** 「词光这个等级指的是哪个义项」只能由等级反推，无法证实。这是本审计最大的方法局限。
