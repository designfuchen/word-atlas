01先说清一件事：这是生成物，不是编纂物

权威词表（Oxford 3000、NGSL、AWL、EVP）的权威性来自三件事：有语料库依据、有编纂者署名、有版本与修订记录。 词光在这三项上都是空的——但项目自己也说清楚了：

“释义、例句与搭配由大语言模型按统一词典规范撰写……经过自动结构与一致性校验，但尚未逐条人工审校，可能有错。 不是官方雅思词表，也不承诺提分。” —— README

docs/dataset.md 里 cefr 字段的定义是「估计难度」。这是诚实的表述，但也意味着： 这份词表在定义上就不是「权威分级」，而是「一个自洽的估计值」。所以审计的重点不该是「符不符合某本标准」， 而是「在没有标准可依的情况下，它的选词与标注是否经得起外部检验」。

04边界：12.3% 落在长尾

用 OpenSubtitles 50k 词频表给每个词定位，看有多少落在「3 万位之后或根本不在榜」。

按词光自报等级分组，仅统计 7,210 个单词词头；红色段为 886 个长尾词（不在榜者按 50,001 计）。88 个多词/连字符条目不在分母内。

长尾集中在 C1/C2，这是合理的

886 个长尾词里，C1 有 510、C2 有 204，占 81%。 高级词本来就低频，这部分不是问题。

真正扎眼的是 A1 2 个、A2 23 个、B1 33 个： photocopier（A2）、rucksack（A2）、dustbin（A2）、ladybird（B1）—— 词频都在 2 万位之后，标成 A2/B1 更像「教材里出现过」而不是「学习者该先会」。

98 个专有名词没有单独归类

7 个星期、10 个月份、25 个地名、16 个国籍/语言，另有 God Bible Islam Marxism Leninism Saturn PC ZIP code。

专有名词进词表没问题，但它们与普通词混在同一个分级体系里， 既拉低了「A1 词汇量」的含金量，也让 CEFR 对照失真（EVP 基本不收专有名词）。

05内部一致性：拼写和词形的双标

这是最能说明「缺少编纂规范」的一组证据——同一件事，词表内部有两种做法。

问题数量例子
同一词的英美拼写都收12 组favourite + favorite、organise + organize、grey + gray、programme + program
只收英式拼写8 组colour、centre、theatre、metre、defence、offence、neighbour、travelling
只收美式0 组—
英美不同词都收（非拼写变体）15 组film + movie、flat + apartment、lorry + truck、petrol + gas、biscuit + cookie
两个词合并成一个词头1 条cheque/check（词头带斜杠，全库唯一）
原形与屈折形并存5 组chip + chips、child + children、foot + feet、woman + women、person + people
过时连字符写法72 个dining-room、tape-recorder、mid-day、bread-earner、epoch-making
大小写错误2 条TRUE、FALSE 全大写（应为 true / false）
词头形式不规范1 条Mister（词典词头应为 Mr / mister）
月份不成套缺 2 个有 10 个月份，缺 March（并入 march 动词）与 May（may 整个词都没有）

这些不是内容错误，是没有编纂规范的症状：如果先定一条规则（「本表为英式拼写，美式变体只在差异显著时单列」）， 上面 8 类问题会自动消失。它们目前是随机分布的，说明每条词目是独立生成的，没有横向对齐。

06分级：经验上站得住，标准上对不上

各等级词头在 OpenSubtitles 50k 词频表中的中位排名（对数刻度）；数字越小越高频。

中位排名从 A1 的 866 一路单调升到 C2 的 30,603，等级与词频的秩相关 ρ = 0.71。 这说明分级不是拍脑袋：它确实跟着「这个词有多常用」在走。作为一份没有语料库支撑的估计值， 这个内部一致性是可信的。

但和 EVP 对照就露馅了——上一份报告的结论：只有 54.2% 的等级与 EVP 首个义项一致， 整体偏乐观 0.44 级，C1 段有 71% 被 EVP 判为 C2。也就是说： 词光的等级是一把自洽的尺子，但刻度比 CEFR 松半格，越往上松得越多。

归纳一下：词光的「专业性」在工程层面是过关的——字段齐全、音标 100%、双例句 100%、搭配 100%、 结构校验通过、等级与词频单调对应；缺的是「权威性」的三根支柱：可追溯的来源、可核验的引用、可复现的选词规则。 前者是产品力，后者是学术信用，两件事不能互相替代。

07要补的话，按这个顺序

  • 补 46 个 AWL 词族（aspect / potential / emphasis / contrast / phenomenon / whereas / acknowledge / foundation / infrastructure / scenario / trigger…）。这是雅思场景下回报最高的一步，46 条就能补上学术骨架。
  • 补高频实义词：实义动词 5 个（go / work / thank / check / reveal），高频形容词 7 个（happy / deep / entire / likely / past / religious / federal）。数量少，但都是「学习者一定会遇到」的词。功能词（be / have / do / would / may 等）若不收，应在文档里写明是刻意的边界。
  • 确定拼写政策并统一执行：要么纯英式（删掉 12 个美式重复项），要么双收但加 variant 字段。同时清理 cheque/check、TRUE/FALSE、Mister。
  • 给词表加三列元数据：freq_rank（语料排名）、source（NGSL / AWL / COCA 频段 / 话题补充）、proper（专有名词标记）。数据已在 headword-audit.csv 里，合并即可。
  • 把 cefr 改名或加注：叫 cefr_estimate，并在 UI 上写「参考 CEFR 的估计难度」，避免读者误以为是官方分级。
  • 放开义项上限：现在全库每个词最多 3 个义项，而 in 在 EVP 里有 15 个。建议对高频词按需扩展到 5–6 个，低频词保持 1–2 个。
