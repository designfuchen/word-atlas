01两个词表不是同一种东西

先把分母对齐。EVP 的「一条」是一个义项，词光的「一条」是一个词。

EVP 官网自身的列表里存在 1,110 条完全重复的行（按「词头+义项标记+等级+词性」判定），去重后为 14,586 条义项。

EVP 的「义项标记」是 guideword，例如 a 有三条：NOT PARTICULAR / ANY/EVERY / ONE，都是 A1。 单词头里义项最多的是 on（19 个）和 take（18 个），从 A1 一路铺到 C2； 如果把以 in 开头的短语词条也算进来，in 名下共 171 条记录。词光这边 in 是 A1、3 个中文义项。 当一个词在参考体系里横跨 6 个等级时，「给这个词一个等级」本身就已经丢掉了大部分信息。

02覆盖率断层：C1/C2 几乎对不上

按词光自己的等级分组，看有多少词能在 EVP 里找到。

分母为词光各等级词数；分子为在 EVP（英式）中能匹配到词头或短语词头的词数。

A1 到 B1 的覆盖率在 89–96%，到 B2 掉到 73%，C1 只剩 26%，C2 只有 1.5%（274 个词里 4 个）。 换句话说，词光越往上走，越是在说 CEFR 之外的东西。

词光的 C1/C2 在 EVP 眼里是什么

1,882 个 C1/C2 词（占词光 25.8%），只有 423 个能在 EVP 找到，占 22.5%。
其中 271 个被 EVP 判为 C2，其余散落在 B2/C1。

例：threshold inherent empirical whereby curb infer 词光标 C1，EVP 全部是 C2。

EVP 的 C2 词在词光眼里是什么

EVP 有 1,710 个 C2 单词头，词光收了其中 1,113 个（65%），但绝大多数被标成 B2/C1。

而词光自己的 274 个 C2 词——avenge bestow deplore vortex preclude staphylococcus——基本都不在 EVP 里。两套「高级词」几乎不重叠。

03等级一致率：取决于你怎么把义项压成一个词

CEFR 没有「词的等级」，只有「义项的等级」。要跟词光的单词级标签比，必须先选一个归并规则——选哪个，结论完全不同。

以 4,838 个可比词为分母。min = 取该词最易义项的等级；mode = 义项数最多的等级；max = 最难义项。

取最易义项（min）：54.2% 完全一致，93.2% 在 ±1 级内，平均偏差 −0.44 级。这个口径下两套体系其实是「基本对得上」的， 因为词光的等级大致等于「这个词该在第几级第一次出现」，而这正是 EVP 最易义项的含义。

取最难义项（max）：完全一致掉到 31.6%，±1 级内只有 66.3%，平均偏差 −1.29 级。 同一批词、同一批数据，只是换了个归并规则，一致率就从 93% 掉到 66%。这个落差本身就是答案： 词级标签的「准确率」不是词表质量问题，而是定义问题。

词光等级 × EVP 最易义项等级

行 = 词光标注，列 = EVP 该词最易义项的等级；格子数字为词数，颜色深浅为该行占比。

矩阵不是随机噪声，是一条稳定的斜线向右下方偏移：

  • 词光 A1 → EVP A2 及以上的有 253 个，占 A1 组的 34%
  • 词光 A2 → EVP B1 及以上的有 420 个，占 45%
  • 词光 B2 → EVP C1/C2 的有 655 个，占 44%
  • 词光 C1 → EVP C2 的有 271 个，占 71%

也就是说：词光系统性地比 CEFR 乐观约半级，越往高级偏得越多。这不是随机误差，是整体标尺的偏移。

05三类系统性偏差

A. 把「概念简单」当成「学得早」

词光标 A1、EVP 标 B1 的一大批词，都是具体名词——概念上三岁小孩都懂，但教学大纲里出现得晚：

词词光EVP说明
rainy / toothpaste / tiger / giraffe / strawberryA1B1具体名词，教材出现晚
gym / lady / writer / pants / alphabetA1B1同上
tool / lower / gardening / mother-in-lawA2B2差 2 级
CEFR 的等级来自语料库与教材的实际出现顺序，不是概念难度评分。

B. 词光标的是「另一个义项」

词词光EVP 各义项错位原因

这类差异不是「标错」，而是两个体系讨论的不是同一个东西。

C. 高级段越界

词光的 C1/C2 有大量 EVP 根本没收录的词：avenge bestow deplore splint infantry depute wreathe vortex preclude surmise staphylococcus pilferage——偏文学、偏生僻、甚至专业术语。CEFR 的 C2 不是「最难的词」，而是 「熟练使用者仍会用到的高阶词」，两者词表天然不同。

06结论

「出入巨大」是真的，但它不是准确率问题。把词光的等级和 EVP 最易义项对比，93.2% 在 ±1 级内——作为单词级标注， 这个精度已经相当好。真正巨大的出入在三个地方：

1. 覆盖：31.9% 的词在 EVP 里不存在；C1 段 74%、C2 段 98% 不在。
2. 义项：词光的标签平均只能解释 29% 的义项；44.3% 的词一个义项都对不上。
3. 标尺：词光系统性乐观约半级，C1 段偏差达 −0.68 级，71% 的 C1 词被 EVP 判为 C2。

如果要把词光接到 CEFR 上

  • 不要给词一个等级，给一个区间。用 evp_min–evp_max（如 bear: A2–C2），比单值诚实得多；数据已在 atlas-vs-evp.csv。
  • 义项级对齐。词光已有 senses[]，把每个中文义项对到 EVP 的 guideword，等级挂在义项上，才是 CEFR 的原意。
  • 给 C1/C2 加「超出 CEFR 范围」标记。EVP 只有 6,547 个单词头，词光有 7,282 个，必然有 30% 越界；越界不是错，但需要标注，否则用户会以为 CEFR 认可这个分级。
  • 校准整体偏移。若要保留单词级标签，把 B2 及以上整体上调约半级，能显著提高与 EVP 的一致性。

07方法与局限

  • 抓取：站点是 Bubble 单页应用，数据经 Elasticsearch 加密传输。通过浏览器把 Display 设为 All、逐屏滚动触发渲染，从 DOM 抽取全部 15,696 行（与站点自带计数一致）；美式词表同法抓取 15,389 行。
  • 去重：官网列表含 1,110 条完全重复行，按四元组去重后 14,586 条义项。
  • 匹配：优先精确词头；其次「冠词/助动词 + 词」与短语首词（the moon、depend on/upon sb/sth）；再退到词形还原；最后是短语内嵌。等级比较只使用前两类，并剔除专有名词，共 4,838 词。
  • 局限：未做义项级语义对齐，因此「词光指的是哪个义项」只能靠等级反推；EVP 的 BrE/AmE 两版等级略有差异，本报告以英式为主；2,325 个未匹配词中约 59 个可在美式词表找到，其余多为专有名词、美式用法或超出 EVP 范围。
