# 学习模型 / Learning model

## 每日旅程

- **复习**：所有到期的词（FSRS 计算的 `due` 已过）。
- **新词**：每天上限可设（默认 10），从学习路线中你的起点难度开始取未学过的词。
- 顺序：先复习，再以 5 个为一组学新词：先「初见」认识 5 个词，再打乱顺序回忆这 5 个词。

## 题型

| 题型 | 适用 | 说明 |
| --- | --- | --- |
| 选义 | 新词、记忆弱 | 看英文选中文，干扰项词性相同 |
| 看图补句 | 新词、记忆弱 | 插画 + 挖空例句，选英文词，干扰项拼写相近 |
| 听音辨词 | 各阶段 | 只听发音选词 |
| 拼写 | 稳定度较高 | 看图和释义拼写，可以逐字母提示（提示后最多计 Hard） |

## 评分与 FSRS

每个词在一轮中只有**第一次作答**更新记忆（ts-fsrs，FSRS-6，默认目标记忆率 90%）：

- 答错 → Again
- 答对但慢、或用了提示 → Hard
- 答对 → Good；拼写又快又对 → Easy

答错的词会在几题之后换一种题型再练一次（最多两次），重试不再评分，也不计入正确率。

### 词的三种状态

| 状态 | 怎么来的 | 会不会出现在今天的计划里 |
| --- | --- | --- |
| 未学 | 从来没遇到过 | 会被当作新词 |
| 学习中 | 有 FSRS 卡片，还没达到掌握阈值 | 会，到期就复习 |
| 已掌握 | ① 复习到记忆稳定度 ≥ 21 天，或 ② 你自己手动标记 | **不会**：不学、不复习，但仍算「点亮」 |

「已掌握」有两个来源，对用户是同一个词：手动标记与 FSRS 达标**等价**。区别只在于手动标记
可以撤销（只标记未答题的回到「未学」，答过题的保留记忆回到「学习中」），自动达标的不提供撤销。
入口有三处：词条面板的按钮或 <kbd>K</kbd> 键、图鉴列表每行右侧的圆点、学习页「初次见面」的
「早就认识它」。细节见 [mark-mastered.md](mark-mastered.md)。

## 打字练习

打字只训练输出，不改变记忆状态。WPM 按每 5 个正确字符计 1 词。
