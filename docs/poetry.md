# 诗词 / Poetry

在词光里学古诗：读诗、看拼音，用间隔复习背诵。入口是顶部导航的「诗词」（`#/poetry`）。

目前收录 176 首唐诗，数据整理自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，授权见 [CONTENT_LICENSE.md](../CONTENT_LICENSE.md) 和 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 词库格式

### `data/poetry.json`

一个数组，按学习路线排序（体裁由易到难，同级内短诗在前）。每首诗：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | URL 安全的唯一标识，由标题和作者的拼音生成，例如 `ba-zhen-tu-du-fu`。同时是学习进度的键，不要随意改动 |
| `title` / `author` | string | 题目、作者（简体） |
| `dynasty` | string | 朝代，目前都是 `唐` |
| `form` | string | 体裁：五言绝句、七言绝句、五言律诗、七言律诗、五言古诗、七言古诗、乐府、其他 |
| `themes` | string[] | 题材标签，另含学段标签 `小学古诗`、`初中古诗`、`高中古诗`。不在《唐诗三百首》里的诗，这里大多是空的 |
| `level` | number | 0–3，由体裁决定：绝句较易，古诗和乐府较难 |
| `lines` | `{zh, py}[]` | 每句一项（按 `，。？！；` 拆开，标点留在句尾）。`py` 与 `zh` 的字一一对应，标点位置是空串 |
| `gist` | string | 白话大意。默认留空，见下面的「已知问题」 |

### 网页数据 `public/poetry/`

- `index.json`：紧凑索引。`poems` 中每行为 `[id, title, author, formIndex, level, lineCount, themeIndexes, firstLine]`，`firstLine` 是首句去掉句末标点，供列表显示，`forms`、`levels`、`themes` 是对应的名称表，`chunk` 是每块的诗数（50）。
- `poems/<n>.json`：完整诗词，第 `n` 块对应索引中第 `n*50` 到 `n*50+49` 行。

## 重新生成

需要 Python 3 和两个包：

```bash
pip install pypinyin opencc-python-reimplemented
git clone --depth 1 https://github.com/chinese-poetry/chinese-poetry.git ../chinese-poetry
npm run build:poetry
npm run check:poetry
```

`build:poetry` 运行 [`scripts/poetry/build_poetry.py`](../scripts/poetry/build_poetry.py)，做这几件事：

1. 读取 `水墨唐诗/shuimotangshi.json`（简体，带白话大意，默认不使用）和 `全唐诗/唐诗三百首.json`（繁体，带体裁与题材标签），把后者转成简体后按「题目 + 作者」合并标签。
2. 套用 `TEXT_FIXES` 修正上游的录入错误。
3. 把每首诗拆成单句，用 `pypinyin` 生成逐字拼音，再套用 `READING_FIXES` 修正读音。
4. 判断体裁（有标签用标签，没有就按句数和字数推断）、整理题材（去掉朝代标签、册次标签和近义重复）、排出学习顺序。
5. 写出 `data/poetry.json` 和 `public/poetry/`。

`check:poetry` 检查结构、顺序和拼音与汉字是否一一对应。它不检查语义是否正确。

### 修正表

两张表都在脚本顶部，只收录**确定**的修正：

- `TEXT_FIXES`：`(错误片段, 正确片段)`，同时作用于原文和白话大意（如果带上的话）。例如上游把「远上寒山」写成「远目寒山」。
- `READING_FIXES`：`(句中片段, 字, 读音)`，例如「鬓毛衰」里的「衰」读 cuī。有争议的读音不要放进来。

发现新的错误，加一行再重新生成即可。

## 图鉴

诗词首页（`#/poetry`）是诗词图鉴，有卡片、列表和星图三种视图。卡片和列表可以按下面这些条件筛选：

| 条件 | 说明 |
| --- | --- |
| 搜索 | 题目、诗人或诗句，包含即可；搜诗句时忽略标点，可以跨过两句之间的逗号。命中诗句的诗会在卡片上显示那一句 |
| 学习状态 | 全部、未学、学习中、已掌握、收藏 |
| 体裁 | 五言绝句、七言绝句等 |
| 学段 | 小学古诗、初中古诗、高中古诗（只有出现在《唐诗三百首》标签里的诗才有） |
| 题材 | 至少有 2 首诗的题材 |
| 难度 | 入门、初级、中级、进阶（由体裁决定，见「词库格式」的 `level`） |

卡片上显示题目、首句（搜索命中诗句时换成命中的那一句）和「诗人 · 体裁 · 难度」。开始学的诗右侧有一个进度环：浅色弧是已经问过的联，实色弧是已掌握的联，全部掌握后整圈变绿；没学过的诗不画环。

一首诗的状态由它的联卡片决定：从没被问过是「未学」，有任何一联被问过是「学习中」，所有能出题的联都已掌握是「已掌握」。只有 1 句的诗没有能出题的联，所以不会进入「已掌握」。

筛选条件都写在网址里，可以分享或用浏览器的后退键返回，参数是 `q`、`status`（`new`、`learning`、`mastered`、`saved`）、`form`、`stage`、`theme`、`level` 和 `view`（`grid`、`list`、`galaxy`），其中体裁、学段、题材和难度用名称而不是编号，重新生成数据后链接仍然有效。视图选择会记在浏览器里。

索引里只有题目和诗人，第一次搜索时会加载全部诗词（约 160 KB）来搜诗句；加载完成前，结果只按题目和诗人匹配。

### 星图

每首诗是一颗星：每种体裁占一条旋臂，越难的诗离中心越远，学习时星星会亮起来（未学是暗尘，学习中是金色，已掌握是亮白）。可以拖动旋转、滚动或双指缩放，鼠标停在星星上会显示诗名，点击打开这首诗；触屏上第一次点预览，第二次点才打开。在搜索框输入题目、诗人或诗句，镜头会飞向第一个匹配的星。星图里没有状态、体裁、题材和难度筛选。右侧的分享按钮会把当前星图做成一张 4:5 的海报（支持系统分享时调起分享，否则下载图片）。

学完一轮后的总结页有一张小星图，这一轮学过的诗会逐颗亮成金色。

星图复用了单词星图的渲染引擎（`src/galaxy/engine.ts`），布局在 [`src/poetry/galaxy.ts`](../src/poetry/galaxy.ts)，界面在 `src/poetry/PoetryGalaxy.tsx`。引擎只新增了一个可选参数 `distScale`，诗词只有 176 颗星，镜头要站得比单词星图近；分享海报的文字（`src/galaxy/share.ts`）也改成了可选参数，默认仍是单词星图的文字。设备不支持 WebGL2 时，引擎会退回 2D 画布。

## 学习模型

### 以「联」为记忆单位

一联是相邻两句（上句、下句）。每联一张 FSRS 卡片，卡片 id 是 `<诗 id>:<第几联>`。句数是奇数的诗，最后一句没有对应的下句，不出题，只在诗词页里显示。

一首诗的「已掌握」联数用和单词相同的标准：FSRS 复习状态且记忆稳定度 ≥ 21 天。

### 每日旅程

- **复习**：到期的联，以及已经开始学的诗里从没被问过的联（比如中途退出了）。最多 40 联。
- **新诗**：每天上限可设（1–8 首，默认 2），按学习路线取还没学过的诗。
- 顺序：先复习；再逐首学新诗：先读一遍整首诗（拼音），再打乱顺序回忆这首诗的每一联。
- 诗词页上的「学这首」只练这一首：没学过就先读再答，学过就直接练它的每一联。

### 题型

| 题型 | 适用 | 说明 |
| --- | --- | --- |
| 接下句 | 新卡、记忆弱 | 给上句，选下句。干扰项取字数相同的诗句，优先同体裁、同诗人、同题材 |
| 补全这一句 | 记忆中等 | 下句里挖掉一个字，从 4 个字里选 |
| 排字 | 记忆稳定度高 | 把下句的字打乱，按顺序点出来 |

### 评分

和单词一致：每联在一轮中只有**第一次作答**更新记忆（FSRS，目标记忆率沿用单词设置里的值）。

- 答错 → Again
- 答对但慢（选择题超过 12 秒，排字超过 40 秒）→ Hard
- 答对 → Good；排字又快又对（12 秒内）→ Easy

答错的联会在几步之后换一种题型再练一次（最多两次），重试不评分，也不计入正确率。

### 朗读

朗读用浏览器自带的语音合成（`speechSynthesis`），不含音频文件。程序在设备的语音里挑普通话：大陆口音优先，其次其他中文，避开粤语；有「自然」「增强」之类的语音会优先用。正常语速 0.85，慢速 0.6（诗词页的「慢速朗读」开关）。设备没有中文语音或浏览器不支持时会提示。

- 诗词页：「朗读全诗」，点任意一句只读这一句。
- 学习：读新诗那一步可以朗读全诗，答完题的反馈里可以朗读这一联。

音质、节奏和多音字读得准不准取决于用户的系统，程序无法控制。一部分浏览器（如 Chrome 的联网语音）会把文字发送给浏览器厂商的服务来合成，这不是本项目发出的请求。

### 数据存在哪里

诗词的进度、收藏和偏好只存在浏览器里，和单词的进度分开：

- `word-atlas:v2:poetry-tang`：卡片、收藏、每日统计、错题
- `word-atlas:poetry:prefs`：是否显示拼音、每天新诗数、是否慢速朗读

目前诗词进度还不支持导出和恢复，也不会在多个标签页之间同步。学习会话本身不保存，刷新后会按已保存的卡片重新生成。

## 已知问题

- **上游文本有录入错误**。上面的修正表只覆盖已确认的几处；其余没有逐首核对。两个来源之间也有版本差异（例如「故伎」与「故妓」），目前以简体的《水墨唐诗》为准。
- **拼音是程序生成的**。多音字常读错，只修正了少数确定的读音。
- **没有白话大意**。上游《水墨唐诗》带有白话大意（`prologue`），但没有说明作者和授权，不满足 CC BY 4.0 再分发的要求，所以默认不收录；构建时加 `--with-gist` 可以带上，仅供本地使用。`gist` 字段保留在数据格式里，界面在它为空时不显示「大意」一栏。
- 没有注释和插画，也没有预先录好的朗读音频。
- 106 首诗没有题材标签，因为它们不在《唐诗三百首》里。
- 目前只有唐诗，宋词、诗经等还没有加入。
